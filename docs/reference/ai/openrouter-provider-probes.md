# OpenRouter Provider Probe Runs

Per-model results from `mise run openrouter-probe`, run from a talos session
so egress is the pod's — providers rate-limit by IP, so a pod result is the
prod-relevant one. Each section gives the run date, the egress banner, the
pre-run cost estimate, and the stderr summary table; one section per model,
and when a model is probed again the newer run goes on top of its section.
JSONL record files stay in the pod and are not committed. See
[[probe-openrouter-model]] for the how-to and
[eblume/talos#183](https://forge.ops.eblu.me/eblume/talos/issues/183) for the
consumer issue.
