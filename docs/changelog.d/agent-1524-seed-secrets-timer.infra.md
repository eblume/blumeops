Weekly host systemd timer (`seed-secrets-check.timer`) on ringtail now drives the vault-free `seed-secrets --check` drift gate for the on-host secret files declared in `nixos/ringtail/secrets.json` (the #1524 follow-on): it runs `--check --local` as root (no ssh route from CI, no vault), writes an ok + timestamp textfile metric scraped by ringtail's Alloy, and Grafana alerts on `SeedSecretsCheckFailed` / `SeedSecretsCheckStale` via a new runbook. Part of eblume/blumeops#1524.
