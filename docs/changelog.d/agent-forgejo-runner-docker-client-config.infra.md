The indri flake's generation now strips host-only credential helpers (`credsStore`/`credHelpers`) from the indri-build runner's docker client config on the macOS host. A Docker-Desktop-era `credsStore: osxkeychain` (left over from before the colima migration, eblume/blumeops#1382) was breaking every uncached image pull on the build runner: the host's dagger CLI reads that config for buildkit's session-auth credential callback, and the keychain helper is no longer installed on the host.
