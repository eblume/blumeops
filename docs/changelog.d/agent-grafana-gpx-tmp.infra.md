Grafana container image now ships a world-writable /tmp: 13.x's bundled datasources (Prometheus, Loki, Tempo, ...) are external gpx plugin processes that fail to initialize without a writable /tmp. The home-built image had none and the pod (uid 472, read-only image layer) cannot create one, which left every datasource unregistered and all alert rules erroring with `plugin.notRegistered`.
