The `forgejo_runner` role now strips host-only credential helpers (`credsStore`/`credHelpers`) from the indri-build runner's docker client config, restarting the build VM when it does. A Docker-Desktop-era `credsStore: osxkeychain` (left over from before the colima migration, eblume/blumeops#1382) was breaking every image pull in the build VM: the VM's docker daemon reads that config for registry credentials, and the macOS keychain helper cannot exec inside a Linux VM.
