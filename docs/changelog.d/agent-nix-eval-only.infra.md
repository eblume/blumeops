agent-ws 0.15.0: `nix` in the pod, deliberately eval-only. Its store, state and log dirs are relocated onto the PVC (`~/.local/state/nix`), which needs no root, daemon, namespace or capability — enough for `nix-instantiate`/`nix eval` and the evaluator-side fetchers (`nix-prefetch-url`), and structurally incapable of a useful build, since a relocated `store-dir` can never hit `cache.nixos.org` (`max-jobs = 0` makes that a clean error). Restores what containerization silently dropped: Nix changes to `nixos/ringtail/` and `containers/*/default.nix` no longer reach a human with their syntax unchecked. The agent container's memory limit goes 4Gi → 6Gi to fit a full NixOS evaluation alongside claude.
