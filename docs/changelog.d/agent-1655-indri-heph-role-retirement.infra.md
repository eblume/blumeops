The indri heph role's daemon legs retire now that the rollback window has passed: the cargo install + version gate, the plist template + restart handler, the op-read leg, and the `heph_ansible_managed` gate are deleted - the generation owns the LaunchAgent outright, so a hub rollback is a plain `darwin-rebuild --rollback` to the previous generation. The role keeps the PWA checkout + pwa-version.js stamp and the data dir. A boot-once LaunchAgent (`mcquack.eblume.heph-cargo-bin-cleanup`, the indri twin of ringtail's `heph-cargo-bin-cleanup`) removes the retired `~/.cargo/bin` bins (`heph`, `hephd`, and the v1.8.0-era `heph-tui`/`heph-quickadd` leftovers) so no shell can shadow the store bins.
