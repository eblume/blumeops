Caddy on indri moves from 2.11.4 to the latest upstream release, 2.11.9; the 2.11.5–2.11.9 breaking changes were checked against the rendered Caddyfile (no directive it uses changed). The flake's caddy build is now the only definition, and `configuration.nix` takes it via `specialArgs`, so the deployed binary and the CI build are the same derivation. The gandi DNS plugin moves to v1.2.1 (a libdns bump only).
